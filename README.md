# Saf Safaai Pune Website

Responsive multi-page static website built with HTML, CSS and vanilla JavaScript. No build step is required.

## Pages
Home, All Services, Kitchen Deep Cleaning, Bathroom Deep Cleaning, Sofa Cleaning, Full Home Deep Cleaning, BHK Packages & Pricing, Gallery, About Us, Contact & Book Now.

## Run locally
1. Extract the ZIP.
2. Open a terminal in the project folder.
3. If Python is installed, run `python -m http.server 8000`.
4. Visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `saf-safaai-pune`.
2. Upload all project files/folders to the repository root (keep `index.html` in root).
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After deployment, the site address will be like `https://YOUR-USERNAME.github.io/saf-safaai-pune/`. For a user-site repository named `YOUR-USERNAME.github.io`, it will be `https://YOUR-USERNAME.github.io/`.

## Domain choice
This project intentionally has **no CNAME file**. It uses the GitHub Pages `github.io` address and does not connect `safsafaipune.sbs`. Your existing domain remains yours but will not automatically point to this new site under this option.

## Booking
The booking form creates a WhatsApp message and opens `https://wa.me/919325100228`. The customer must manually review and send it. It does not send messages automatically, store form data on a server, or confirm bookings.

## Voice
The site makes a best-effort browser speech-synthesis attempt once per session. Mobile browsers may block autoplay or lack a suitable voice; the site remains usable without audio.

## Photos and fonts
Images are illustrative stock imagery and are not represented as customer jobs. Photos and Google Fonts are loaded from external URLs, so internet access is needed. Replace these with properly licensed local assets if you prefer self-hosting.
